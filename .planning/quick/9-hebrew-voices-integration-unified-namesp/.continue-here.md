English and only translate at the audio boundary. Google Translate unofficial API
is the right tool: free, fast, no setup, already has httpx installed.

Flow: Claude responds in English → service.py calls translate_to_hebrew() →
_translate_via_google() joins sentences, calls Google API, splits result →
Hebrew sentences queued to TTS worker → LightBlueTTS synthesizes Hebrew audio.

responds in English, is_hebrew() returns False → translation always runs when
Hebrew voice is active. No logic changes needed in service.py.
